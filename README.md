# KBO 투구 제구 성공 확률 예측

데이콘 / LG Aimers 9기 온라인 해커톤. 투구 하나가 **제구 성공**일 확률을 예측한다.
평가지표는 Brier Skill Score.

```
Score = max(0, 100000 x (1 - Brier / (r(1-r))))     # r = 평가 데이터 실제 평균 성공률
```

## 접근

- **CatBoost** 10-fold x 3-seed = 30개 모델 평균, fold 별 isotonic 보정
- **당해 시즌 성적 복원** — `asof_*` 는 커리어 누적이라 투수마다 섞인 시즌 수가 다르다.
  그 시즌 시작 시점의 누적을 빼면 깨끗한 당해 시즌 값이 남는다. 투수 5개 + 타자 2개.
  이 하나가 전체 상승분의 **절반 이상**이다 (+61.7, +30.1)
- **조건부 투수통계** — 시즌 디트렌드 + 0 으로 shrink 한 (투수 x 카운트 x 좌우) 성공률
- **트랙맨 매핑 재구축** — 주최측 제공 매핑이 약 91% 틀려 있어 팀→투수 2단계로 다시 만듦
- **재중심화** — 시즌별 성공률 하락(.5647 → .4861)을 학습 시점에 측정한 로짓 상수로 보정
- **CPU 학습** — CatBoost 는 처리 장치에 따라 기본값이 다르다 (`bootstrap_type` MVS/Bayesian,
  `border_count` 254/128). MVS 는 CPU 전용이라 GPU 로는 절반만 회수된다

## 방법론 메모

이 프로젝트에서 가장 비싸게 배운 것들이다. 자세한 근거는 `claude.md`.

**① 그 행 안에서 계산되는 파생피처는 트리가 스스로 만든다.**
값어치가 난 것은 전부 "다른 행·다른 테이블에서 끌어온" 것이다
(당해시즌 복원 +92, 조건부통계 +27, 트랙맨 +9 / 파생피처 51개 ≈ 0, 백분위 변환 0, 차이 피처 0).

**② 홀드아웃 → 리더보드 전달률은 변경의 *종류*에 달렸다.**
새 정보 x0.85 / 버그 수정 x0.45 / 파라미터·피처 제거 x0.25.
홀드아웃은 학습 데이터가 18% 적은 소표본 체제라 규제·용량 계열을 체계적으로 과대평가한다.

**③ 2024 홀드아웃은 거짓 양성도 거짓 음성도 낸다.**
거짓 양성 4건(+27 → 리더보드 −22)에 더해, 2026-08-23 에 첫 거짓 **음성**이 나왔다 —
타자측 복원이 2024 에서 **+3.0**(노이즈)이었는데 리더보드에서 **+30.11** 이었다.
2023 홀드아웃(퓨처스 행 제외)이 방향을 맞혔다. **두 시즌 다 볼 것.**

**④ 대리지표로 후보를 채택하지 말 것.** 세 번 틀렸다 —
표적과의 상관(+0.260→+0.477 인데 점수 −17.8), 축약 대리모형(+76 인데 실측 +0.9),
반쪽 분할 신뢰도(교정점의 125% 인데 실측 −7.3). 판정은 스크리너 → 리더보드로만 한다.

**⑤ 피처를 뺀 축약 모델로 설계 결정을 내리지 말 것.** 결론의 *방향*이 뒤집힌다.

**기준점**: 공식 베이스라인(RandomForest, 원본 47컬럼)이 같은 2024 홀드아웃에서 415.6,
리더보드에서 549.51. 이 파이프라인이 홀드아웃 886.
