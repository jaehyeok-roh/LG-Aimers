# KBO 투구 제구 성공 확률 예측

데이콘 / LG Aimers 9기 온라인 해커톤. 투구 하나가 **제구 성공**일 확률을 예측한다.
평가지표는 Brier Skill Score.

```
Score = max(0, 100000 x (1 - Brier / (r(1-r))))     # r = 평가 데이터 실제 평균 성공률
```

## 접근

- **CatBoost** 10-fold x 3-seed = 30개 모델 평균, fold 별 isotonic 보정
- **당해 시즌 성적 복원** — `asof_*` 는 커리어 누적이라 투수마다 섞인 시즌 수가 다르다.
  그 시즌 시작 시점의 누적을 빼면 깨끗한 당해 시즌 값이 남는다. 투수 5개 + 타자 2개.
  이 하나가 전체 상승분의 **절반 이상**이다 (+61.7, +30.1)
- **투구 단위 실패유형 라벨 복원** — `asof_pitcher_n` 이 투수 내에서 정확히 +1 씩
  증가하므로 인접 두 행의 차분이 그 투구의 라벨이다. `success` 로 검산해 147만 행
  일치율 **1.000000**. 여기서 두 가지가 나온다:
  - **보조 타겟** — 교차적합한 `P(reverse|X)` 를 피처로 (+13.5)
  - **5분류 타겟** — 0 성공 / 1 몰림만 / 2 반대만 / 3 둘다 / 4 크게벗어남 (+12.9)
  - ⚠️ 차분은 **train 에서만**. test 인접 행 차분은 주최측이 "규칙 위반" 이라 답했다
- **조건부 투수통계** — 시즌 디트렌드 + 0 으로 shrink 한 (투수 x 카운트 x 좌우) 성공률
- **트랙맨 매핑 재구축** — 주최측 제공 매핑이 약 91% 틀려 있어 팀→투수 2단계로 다시 만듦
- **재중심화** — 시즌별 성공률 하락(.5647 → .4861)을 학습 시점에 측정한 로짓 상수로 보정.
  현재 **+116 을 지고 있다** — 배포 점수의 10%가 상수 하나에 걸려 있다

## 방법론 메모

이 프로젝트에서 가장 비싸게 배운 것들이다. 자세한 근거는 `claude.md`.

**① 검증은 2023 을 보고 0.3 을 곱한다.** 여섯 번의 리더보드 실측으로 잡힌 규칙이다.

| 변경 | 2024 | 2023 | 0.3x2023 | 실측 LB |
|---|---|---|---|---|
| wseason5 | +72.2 | +182.1 | +55 | **+61.7** |
| wsbat | **+3.0** | +71.7 | +22 | **+30.1** |
| auxrevns | +22.5 | +55.0 | +17 | **+13.5** |
| mcaux | **+2.8** | +46.6 | +14 | **+12.85** |

2024 홀드아웃은 **거짓 음성을 두 번** 냈다 (`wsbat`, `mcaux` 모두 +3 근처인데 리더보드는 크다).
⚠️ 이 프로젝트는 오랫동안 2024 만 보고 "+50 미만은 노이즈" 로 후보 20개 이상을 버렸다.
**2024 기준으로만 기각한 것은 2023 에서 재측정할 것.**
2023 은 F(퓨처스) 행을 채점에서 빼야 작동한다 (2023 에 판정 체제가 바뀌었다).

**② 파생피처의 재료에서 `season` / `game_type` 을 뺀다.**
같은 아이디어를 보조모델 입력만 바꿔 두 번 제출했더니 전달률이 **0.10 → 0.60** 으로 갈렸다.
`season` 은 cat_features 에 없는 int64 라 분기 경계가 **2023.5** 에서 끝난다 —
그걸 재료로 만든 파생피처는 학습 시대에 얼어붙은 값을 2025 에 뱉는다.
본 모델은 그 둘을 직접 갖고 있으므로 잃는 것이 없다.
(디트렌드 용도, 즉 그 시즌 리그평균을 *빼는* 것은 별개다 — `cond_*`, `w5_*` 는 정상)

**③ 그 행 안에서 계산되는 파생피처는 트리가 스스로 만든다.**
값어치가 난 것은 전부 "다른 행·다른 테이블·다른 라벨" 에서 끌어온 것이다
(당해시즌 복원 +92, 라벨 복원 +26, 조건부통계 +27 / 파생피처 51개 ≈ 0, 백분위 변환 0, 차이 피처 0).
**예외는 범주형 조합** — `is_same_hand` 를 빼면 -17.0/-13.0 이다. 다만 두 개까지고 서로 곱하면 안 된다.

**④ 대리지표로 후보를 채택하지 말 것.** 네 번 틀렸다 —
표적과의 상관, 축약 대리모형, 반쪽 분할 신뢰도, '이론적으로 옳은' 디트렌드 기준.
판정은 스크리너 → 리더보드로만 한다.

**⑤ 피처를 뺀 축약 모델로 설계 결정을 내리지 말 것.** 결론의 *방향*이 뒤집힌다.

**⑥ 조합은 강하게 비가법적이다.** 범주형 조합도(`bsx` +16.2 와 `cnt12` +3.4 를 합치면 -1.2),
보조 타겟도(`reverse` 에 `ball` 을 더해도 +0.002) 하나나 둘에서 최적이다.

**기준점**: 공식 베이스라인(RandomForest, 원본 47컬럼)이 같은 2024 홀드아웃에서 415.6,
리더보드에서 549.51. 이 파이프라인이 홀드아웃 920.
