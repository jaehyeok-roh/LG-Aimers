# KBO 투구 제구 성공 확률 예측

데이콘 / LG Aimers 9기 온라인 해커톤. 투구 하나가 **제구 성공**(포수가 요구한 곳에
던졌는가)일 확률을 예측한다. 평가지표는 Brier Skill Score.

```
Score = max(0, 100000 x (1 - Brier / (r(1-r))))     # r = 평가 데이터 실제 평균 성공률
```

train 은 2019~2024, test 는 2025 다. **항상 미래 시즌을 예측하는 문제**이고,
이 한 문장이 아래 모든 판단의 근거다.

## 결과

```
최종  1,153.6031     973팀 중 **71위 (상위 7.3%)** · 1,926명 중 210번째 (상위 10.9%)
컷    1,171.0985     본선 진출선 = 개인 100명 (상위 5.2%, 팀 36위)  ->  17.5 차이로 미달
출발    932.9600     StratifiedKFold 최초 안정판  ->  최종까지 스킬 +23.6% 상대 개선
```

**상위 7.3% 로 마쳤고 본선 진출선은 넘지 못했다.** 이 저장소의 값어치는 순위가 아니라 그 사이에 남은
기록에 있다 — **리더보드 실측 40여 건**이 각각 *사전 예측 → 근거 → 실측 → 사후분석*
으로 남아 있고, **50건 중 35건이 실패**다. 자기 결론을 실측으로 뒤집은 기록도 여러 건이다.
전체 대장은 **[`EXPERIMENTS.md`](EXPERIMENTS.md)**, 원본 작업 로그는 `claude.md`.

## 발견 넷

**① 평가 행이 몰래 갖고 있던 2025 정보 (+61.7, +30.1)**
`asof_pitcher_success_rate` 는 **커리어 누적**이라 투수마다 섞인 시즌 수가 다르다.
그 시즌 시작 시점의 누적(= train 으로 만든 투수별 룩업)을 빼면 **당해 시즌 값**이 남는다.
같은 컬럼 하나로 예측한 스킬이 이력 있는 투수 141 / 신규 투수 906 으로 **6배** 갈리는데,
신규 투수는 직전 시즌이 없어 그 값이 이미 순수한 당해 시즌 성적이기 때문이다.
투수 5개 + 타자 2개를 복원했고, 이 하나가 전체 상승분의 **40%** 다.

**② 투구 단위 라벨 복원 (+12.9, +9.4)**
`asof_pitcher_n` 이 투수 내에서 정확히 +1 씩 증가하므로 인접 두 행의 차분이
**그 투구의 라벨**이다. 정답이 있는 `success` 로 검산해 147만 행 일치율 1.000000.
여기서 5분류 타겟(성공/몰림/반대/둘다/크게벗어남)과 보조 타겟이 나왔다.
`middle` 은 정답 컬럼이 없어 검산이 안 되는데, **타자측 누적 컬럼으로 독립 복원**해
교차 검증했다 (다른 정렬 키·다른 컬럼·다른 엔티티, 147만 행 일치율 1.000000).

**③ 데이터 산출물 사고를 진단해 +20.6**
특정 팀(13) 관여 경기의 제구 성공률이 2023-05 에 **−0.041 → +0.049 로 부호 반전**한다.
구장 가설은 대조군으로 배제했다 — 12번 팀과 13번 팀은 **같은 잠실**인데 12번은 평평하다.
실패 **구성비**가 실패율만큼 움직인 것(반대만 +6.5pp / 몰림만 −8.0pp)이 결정적이었다:
난이도 변화라면 구성비는 그대로여야 하므로, 바뀐 것은 **포수 요구 지점 판정 방식**이다.
트랙맨으로 확인하니 같은 달에 릴리스 위치 3개와 속도 2개가 동시에 움직였고,
**잠실 안에서 그 팀 경기만** 움직였다 — 하드웨어가 아니라 그 팀 경기 자료였다.

**④ 트리가 못 만드는 구조를 찾아 주기 (+7.8, +3.3)**
대칭트리는 `A==x OR B==x` 를 만들려면 레벨 두 개를 쓴다. 못 만드는 게 아니라 **비싸다**.
저카디널리티 컬럼 쌍 **105개를 전수 스캔**해 2차 상호작용 잔차 강도를 재고,
**2023 잔차 vs 2024 잔차 상관**으로 안정성을 걸렀다. 검증으로 알려진 정답 둘
(`season x t13`, 이미 쓰던 `hand4`)이 상위에 걸렸고, 새로 나온 `phteam` 이 +7.8 이었다.

## 실패에서 나온 규칙

가장 비싸게 배운 것들이다. 근거는 전부 `claude.md` 에 실측과 함께 있다.

**① 검증 지표는 부호조차 못 맞힌다.** 마지막 날 다섯 건에서 홀드아웃과 리더보드는
완전히 무관했다 — 홀드아웃 +17 이 −3.5, +7 이 −10.9, −2 가 −9.2 였다.
중간에 "홀드아웃이 뒤집혀 작동한다" 는 가설을 세웠는데 그것도 틀렸다.
**뒤집힌 게 아니라 정보가 없다.**

**② 근거가 노이즈 밖인지가 부호를 갈랐다.** 같은 '팀 x 무언가' 부류인데
근거가 노이즈 밖이면 +3.3, 안이면 −5.2 와 −9.4 였다. **크기나 그럴듯함이 아니다.**

**③ 포화 측정치는 측정 구간 안에서만 유효하다.** `seed 3→10 = −1.26`(평평)을 근거로
`seed 1` 로 내렸다가 −11.0. "A 에서 B 까지 평평하다" 는 "B 아래도 평평하다" 가 아니다.

**④ '0 으로 측정됐다' 와 '빼도 된다' 는 다르다.** 트랙맨 20개는 스크리너에서
±2 였는데 실제로 빼니 **−5.9** 였다. 보조 타겟도 "타겟이 그 라벨을 담으니 잉여" 라고
빼서 **−3.5** — 타겟이 라벨을 담는 것과 그 확률을 잘 추정하는 것은 다르다.

**⑤ 결측을 '중립값' 으로 채우면 결측 지시자가 지워진다.** `cond_*` 의 NaN 31.7% 를
수식대로 0(리그평균)으로 채웠더니 **−12.2**. 트리는 결측을 자체 분기로 처리하므로
채우기는 '모르는 것' 과 '중립인 것' 을 합쳐버린다. 그리고 그 NaN 집단(신규 투수)이
행당 기여가 가장 높은 구간이었다 — **분석 결과를 갖고 있으면서 후보 설계에 못 이었다.**

**⑥ 한 행 안에서 계산되는 파생피처는 트리가 스스로 만든다.** 값어치가 난 것은 전부
"다른 행·다른 테이블·다른 라벨" 에서 끌어온 것이다 (당해시즌 복원 +92 / 라벨 복원 +26 /
조건부통계 +27 대 파생피처 51개 ≈ 0, 백분위 변환 0, 차이 피처 0).
**예외는 범주형 조합** — 트리가 못 만드는 게 아니라 비싸서다.

**⑦ 대리지표로 후보를 채택하지 말 것.** 네 번 틀렸다 — 표적과의 상관, 축약 대리모형,
반쪽 분할 신뢰도, '이론적으로 옳은' 디트렌드 기준.

**⑧ 한 점 빼고 맞혀볼 것.** 외삽 모형을 세울 때 이 검증이 224점 / 46점짜리 실수를
세 번 막았다. 총합이 좋아 보이는 모형이 정상 연도만 보면 뒤집히는 경우가 있다.

## 구조

```
aimers_v10wtor.ipynb          최종 제출본 학습 노트북 (전처리 -> 학습 -> zip 조립까지 자체 완결)
EXPERIMENTS.md                **실험 대장** — 제출 50건의 근거·예측·실측·사후분석
claude.md                     작업 로그 4,100줄. 가공 안 된 원본 기록
experiments/v10w/             v10w 계열 실험 49개 · experiments/archive/ 이전 세대
tools/                        빌더 37 · EDA 67 · 검증 3 · 스크리너
out/                          EDA 결과 텍스트 · 피처 중요도
data/  model/  archive/       원본 데이터 · 룩업 테이블 · 옛 산출물 (git 제외)
```

노트북은 손으로 고치지 않는다. `tools/mk_*.py` 가 이전 판에서 **생성**하므로
피처를 추가하려면 빌더를 고친다. 전처리는 `STEPS_SRC` 문자열 하나에 정의해
학습 노트북과 제출용 `script.py` 가 **같은 소스**를 공유한다 — 이 원칙이 깨져서
학습/추론 불일치로 36점을 흘린 적이 있다.

## 검증 도구

제출 하나가 하루치 기회이므로, 조용히 죽는 실패를 잡는 데 도구를 따로 만들었다.

| | |
|---|---|
| `tools/audit_independence.py` | 주최측의 **행 독립 예측 시험**. 한 행만 넣을 때와 전체를 넣을 때 예측이 같은지 |
| `tools/verify_ws_live.py` | 상수가 `script.py` 까지 실제로 전달되는지 **대조군**으로 확인. 상수가 조용히 무시돼도 크래시는 안 난다 |
| `tools/nbcheck.py` | 정의보다 먼저 쓰는 이름을 잡는다. 같은 유형으로 커널 4개가 죽은 뒤 만들었고 **7건을 푸시 전에 잡았다** |
| `tools/leaderboard.py` | 100번째 **개인** 컷 계산. 점수가 두 형태로 섞여 있어 절반만 잡으면 "우리가 1위" 가 나온다 |
| `tools/screen.py` | 후보를 제출 없이 판정. 재앙 필터로만 쓴다 (분해능이 목표 효과보다 크다) |

**기준점**: 공식 베이스라인(RandomForest, 원본 47컬럼)이 같은 2024 홀드아웃에서 415.6,
리더보드에서 549.51.

⚠️ 남은 격차의 상당 부분은 **원리적으로 도달 불가능**하다. 무작위 fold(그 투수의
당해 시즌 다른 투구를 봄)와 투수x시즌 그룹 fold 를 비교하면 격차 178 중 **124 가
'이 투구 이후를 아는 것'** 에서 온다. 평가 시점에는 존재하지 않는 정보다.
