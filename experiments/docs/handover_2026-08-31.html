04 / 계산제출 전에 점수를 예측하는 식

평균이나 퍼짐을 건드리는 변경은 제출하지 않고도 부호를 알 수 있다. 세 식 모두 리더보드 실측으로 검증됐다.

재중심화 어긋남 = 100000 × Δ평균² / r(1−r)        r ≈ 0.475
수축           = (1.92λ − λ²)/0.9216,  λ* ≈ 0.96,  λ = std 비
표적 분할 비용  ≈ −23  (5분류 기준, 출력 하나당 약 −6)

검증 사례. 트리를 1000→700 으로 자른 n700 에 이 식을 미리 적용해 −1.3 을 예측했고 실측이 −1.47 이었다. 잔차 −0.17 이 곧 '트리 700~1000 의 실제 기여' 이고, 그 한 줄로 용량 축이 5분류에서도 닫혔음이 확정됐다.

총합이 노이즈 안이어도 예측을 박아두면 결론이 난다

나는 이 제출을 "기대 −1±1.5 라 아무것도 못 배운다" 며 말렸다. 틀렸다. 싼 실측을 기대 효과 크기를 근거로 말리지 말 것.

05 / 방법새 후보를 찾는 유일한 절차

마지막 이틀의 +28.4 는 전부 이 절차에서 나왔다. 다른 방법으로 찾은 후보는 같은 기간에 전부 0 이하였다.

1. 저카디널리티 축 쌍의 2차 상호작용 잔차를 전수로 잰다
       r_ab = mean(y|a,b) − mean(y|a) − mean(y|b) + mean(y)
       강도 = Σ 비중 × r²   →   401,000 × 강도 = 완벽히 잡았을 때의 점수

2. 2023 잔차 vs 2024 잔차 상관으로 거른다   (2025 는 전환 후 체제다)

3. 강도 × 상관 이 phteam(15) 급이면 후보.  hand4(50)가 상한 교정점

4. 범주형 조합으로 직접 준다

절차가 스스로를 검증했다. 1위로 season × t13(202)을 짚었는데 그건 전날 +20.58 로 회수한 것이고, 2위 pitcher_hand × batter_hand(49.5, 상관 1.00)는 이미 hand4 로 모델에 있는 것이다. 알려진 정답 둘을 맞혔다.

왜 하루를 놓쳤나

전날 구장(홈팀)별 편차를 이미 쟀고 13 만 t=−8.95 로 혼자 튀었다. 그런데 10개 구장을 평균 내서 "std 0.0052 / 인접시즌 상관 0.207 / 천장 2점" 으로 닫았다.
평균과 상관은 하나가 크게 튀는 것을 지운다. 세그먼트 축을 집계 두 숫자로 닫기 전에 반드시 개별 항목의 시계열을 눈으로 볼 것.

모델이 못 잡은 이유는 세 겹이다 — ① team13 관여 는 두 컬럼의 OR 이라 대칭트리가 레벨 두 개를 써야 한다 ② 전환점이 5월인데 game_month 를 버렸다 ③ 6시즌을 뭉치면 4시즌 음수 / 2시즌 양수라 상쇄된다. 2025 에 필요한 건 양수 체제 하나뿐이다.

07 / 규정절대 어기면 안 되는 것

주최측 공지: "실격 사례도 지속적으로 발생하고 있습니다." 평가 데이터의 각 행은 독립적으로 예측되어야 한다.

  • 행 A 의 예측에 쓸 수 있는 것은 넷뿐 — ① 행 A 의 입력 ② 그것만으로 만든 파생변수 ③ 공식 학습 데이터 ④ 학습 데이터만으로 만든 통계·모델
  • test 인접 행 차분은 금지다 (주최측이 명시적으로 "규칙 위반" 이라 답했다). 우리 라벨 복원은 train 에서만 하므로 해당 없다.
  • test 전체 평균·분포로 보정하는 것도 금지다. 세그먼트 상수를 중심화할 때 test 평균이 아니라 학습 빈도를 쓴 이유가 이것이다.
  • 판정 시험: 어떤 행의 예측값이 그 행 1개만 있을 때와 전체가 있을 때 같아야 한다.
제출 전 필수:  python tools/audit_independence.py <zip>
현행 실측:     최대 차이 1.11e-16  ✅

팀13 지시자는 행 자기 컬럼 + train 라벨 통계 상수라 허용 범위 안이고, CatBoost 는 이미 pitcher_team_id 에 CTR(타겟 인코딩)을 돌린다 — 부류상 새로운 것이 아니다. 다만 해당 참가자가 문의 중이고 주최측 답변은 아직 없다.
